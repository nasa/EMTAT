Heat Sink

Block Inputs

Tcool_In - Input cooling fluid temperature, degF (1x1)
Ploss - Component power loss, W (1x1)
Win - Input cooling fluid mass flow rate, lbm/sec (1x1)
WC - Mass flow rate of cold fluid, lbm/sec (1x1)
Ploss(t-1) - Component power loss delayed by one time step, W (1x1)

Block Outputs

T - Component temperature, degF (1x1)
Tcool_Out - Output cooling fluid temperature, degF (1x1)
Wout - Output cooling fluid mass flow rate, lbm/sec (1x1)
Outputs - Bus of Block Inner Variables
Ploss - Component power loss, W (1x1)
T - Component temperature, degF (1x1)
Tcool_In - Input cooling fluid temperature, degF (1x1)
Tcool_Out - Output cooling fluid temperature, degF (1x1)
G - thermal conductance, W/degF (1x1)
W - Cooling fluid mass flow rate, lbm/sec (1x1)
Ploss(t) - Component power loss to be delayed by one time step, W (1x1)

Block Mask

Cp - Specific heat of cooling fluid, BTU/(lbm-degF) (1x1)
Wvec - Cooling fluid mass flow rate for thermal conductance table, lbm/sec (1xn)
Gvec - Thermal conductance table values, unitless (0-1) (1xn)

Block Calculations

General Variables

t - time, sec
n - number of cooling fluid mass flow rate and thermal conductance breakpoints, unitless
