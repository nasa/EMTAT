Cable with Temperature Dependence

Block Inputs

V_1 - Voltage In, V (n x 1)
I = Current Out, A (n x 1)
Fail? - Failure Toggle, 0 = Normal Operation/1 = Failure (n x 1)
T - Cable temperature, degF (n x 1)
I(t-1) = One Step Time Delayed Current Out, A (n x 1)

Block Outputs

V_2 - Voltage Out, V (n x 1)
Outputs - Bus of Block Inner Variables
P_2 - Electrical Power Out, W (n x 1)
P_1 - Electrical Power In, W (n x 1)
I = Current In, A (n x 1)
V_1 - Voltage In, V (n x 1)
V_2 - Voltage Out, V (n x 1)
R - Resistance, ohm (n x 1)
Ploss - Power Loss, W (n x 1)
T - Cable temperature, degF (n x 1)
Ploss - Power Loss, W (n x 1)
I = Current In, A (n x 1)
I(t) = Current Out to be One Time Step Delayed, A (n x 1)

Block Mask

T0 - Initial cable temperature, degF (1 x n)
R0 - Initial cable resistance, ohm (1 x n)
alpha - Cable temperature coefficient, unitless (1 x n)

Block Calculations

General Variables

t - Time, sec
n - Size of Input/Output Vector
