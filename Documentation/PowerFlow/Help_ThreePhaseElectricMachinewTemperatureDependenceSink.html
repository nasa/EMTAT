Three Phase Electric Machine with Temperature Dependence (Sink)

Block Inputs

V_LN_rms - Line to Neutral Root-Mean-Square Voltage, V_rms (1 x 1)
N - Rotational Velocity, rpm (1 x 1)
Trq* - Torque Setpoint, lbf-ft (1 x 1)
Fail? - Failure Toggle, 0 = Normal Operation/1 = Failure (1 x 1)
T - Electric Machine Temperature, degF (1 x 1)
I_L_rms(t-1) - Line Root-Mean-Squared Current delayed by one time step, Irms (1 x 1)

Block Outputs

Trq - Torque, lbf-ft (1 x 1)
Outputs - Bus of Block Inner Variables
Pmech - Mechanical Power, W (1 x 1)
Pelec - Electrical Power, W (1 x 1)
Eff - Efficiency (1 x 1)
I_L_rms - Line Root-Mean-Squared Current, Irms (1 x 1)
V_LN_rms - Line to Neutral Root-Mean-Square Voltage, V_rms (1 x 1)
N - Rotational Velocity, rpm (1 x 1)
Trq - Torque, lbf-ft (1 x 1)
Ploss - Power Loss, W (1 x 1)
Trqset or T* - Torque Setpoint, lbf-ft (1 x 1)
OCFail - Open Circuit Failure, 0 = No Failure/1 = Failure (1 x 1)
T - Electric Machine Temperature, degF (1 x 1)
Ploss - Power Loss, W (1 x 1)
I_L_rms - Line Root-Mean-Squared Current, Irms (1 x 1)
I_L_rms(t-1) - Line Root-Mean-Squared Current to be delayed by one time step, Irms (1 x 1)

Block Mask

C_FeVec - Iron Loss Coefficients [C_Fe_1, C_Fe_2, C_Fe_3], unitless (1 x 3)
C_CuVec - Copper Loss Coefficients [C_Cu_1, C_Cu_2], unitless (1 x 2)
Nvec - Speed Breakpoint Vector for Current Lookup in Iron Loss Function, rpm (1 x n)
Icontvec - Continuous Root-Mean-Squared Current Vector for Current Lookup in Iron Loss Function, Arms (1 x n)
alpha_Cu - Copper Temperature Coefficient, 1/degF (1 x 1)
R0_Cu - Initial Copper Resistance, ohm (1 x 1)
alpha_Fe - Iron Temperature Coefficient, 1/degF (1 x 1)
R0_Fe - Initial Iron Resistance, ohm (1 x 1)
T0 - Initial Temperature, degF (1 x 1)
Mode: 0 - No Fault, 1 - Open Circuit Fault

Block Calculations

General Variables

t - time, sec
n - Size of Speed and Contniuous Current Vectors in Iron Loss Function Current Lookup
